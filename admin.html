Important Information

Tables to be backed up:

Restore from Backup

⚠️ WARNING: Destructive Operation

  • • This will REPLACE ALL CURRENT DATA with backup data
  • • All existing users, transactions, and settings will be overwritten
  • • This action CANNOT BE UNDONE
  • • Create a backup of current data before restoring
  • • Banned users will be restored with their ban status

How to Use Backup & Restore

📥 Creating a Backup:

  1. Click "Create & Download Backup" button
  2. A JSON file will be downloaded to your computer
  3. Store this file in a secure location
  4. File name format: easybooster-backup-YYYY-MM-DD.json

📤 Restoring from Backup:

  1. Create a backup of current data first!
  2. Click "Choose File" and select your backup JSON file
  3. Click "Validate Backup" to check if the file is valid
  4. Review the validation results carefully
  5. If valid, click "Restore Database"
  6. Confirm the operation (cannot be undone!)
  7. Wait for the restore process to complete

🔒 What's Included in Backup:

  • All users (including banned users with ban status)
  • All transactions and payment history
  • Auto-react channel subscriptions
  • Request history and rate limits
  • System statistics and settings
  • AI chat history
  • User notifications

Pro Tip: Create regular backups (daily/weekly) to prevent data loss. Store backups in multiple locations.
