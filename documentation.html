Introduction

The ANDY RCH API allows you to programmatically send reactions to WhatsApp channel posts. This API is perfect for automating your social media engagement workflows.

Base URL: https://easyboostervip8.vercel.app

Authentication

All API requests must be authenticated using an API key provided in the Authorization header with the Bearer scheme. 

Authorization: Bearer YOUR_API_KEY

Security: Keep your API key secure and never share it publicly. Contact the administrator if you need an API key.

Send Reactions

Send emoji reactions to a WhatsApp channel post.

POST /api/v1/react

Request Headers

Header Type Required Description
Authorization string ✅ Yes Bearer token with your API key
Content-Type string ✅ Yes Must be application/json

Request Body

Parameter Type Required Description
channelLink string ✅ Yes Full WhatsApp channel post URL (e.g., https://whatsapp.com/channel/XXXX/123)
emojis array ✅ Yes Array of emoji strings (1-16 emojis). Example: ["❤️", "👍", "🔥"]

Example Request

curl -X POST https://easyboostervip8.vercel.app/api/v1/react \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "channelLink": "https://whatsapp.com/channel/0029VaCCYBXGehGLiMpKO03B/123",
    "emojis": ["❤️", "👍", "🔥"]
  }'
const response = await fetch('https://easyboostervip8.vercel.app/api/v1/react', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    channelLink: 'https://whatsapp.com/channel/0029VaCCYBXGehGLiMpKO03B/123',
    emojis: ['❤️', '👍', '🔥']
  })
});

const data = await response.json();
console.log(data);
import requests

url = 'https://easyboostervip8.vercel.app/api/v1/react'
headers = {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
}

    'channelLink': 'https://whatsapp.com/channel/0029VaCCYBXGehGLiMpKO03B/123',

response = requests.post(url, headers=headers, json=data)
print(response.json())

Rate Limits

Each API key has a request limit set by the administrator. You can check your remaining requests in the response: 

"rateLimit": {
  "remaining": 47,  // Requests remaining
  "limit": 50       // Total limit
}

Once your API key reaches its limit, you'll receive a 401 Unauthorized error. Contact the administrator to increase your limit.

Error Handling

All error responses follow a consistent format: 

{
  "success": false,
  "message": "Error description here"
}

Always check the success field to determine if the request was successful.

Best Practices

  • Validate URLs: Ensure channel links are in the correct format before making API calls.
  • Handle Errors: Implement proper error handling for all possible error codes.
  • Monitor Usage: Track your API usage to avoid hitting rate limits.
  • Secure Keys: Never expose your API key in client-side code or public repositories.
