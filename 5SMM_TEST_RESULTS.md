- Using `smmService.js` wrapper

### To Add New Services:

1. **Backend (server.js):**
```javascript
// Add new endpoint
app.post('/api/smm/instagram/followers', requireAuth, async (req, res) => {
    const { link, quantity } = req.body;
    const serviceId = 17845; // Instagram Followers service
    
    try {
        const order = await smmService.createOrder({
            service: serviceId,
            link: link,
            quantity: quantity
        });
        
        res.json({ success: true, data: order });
    } catch (error) {
        res.json({ success: false, message: error.message });
    }
});
```
